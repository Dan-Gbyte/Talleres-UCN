# Taller 1: Sistema de Gestión de Actividades y Usuarios (POO)


Este proyecto es una aplicación de consola desarrollada en Java para el Taller 1 de Programación Orientada a Objetos. El sistema permite la gestión de usuarios mediante un sistema de inicio de sesión y ofrece funcionalidades CRUD (Crear, Leer, Actualizar, Eliminar) para el registro de actividades diarias. Además, cuenta con un módulo de análisis de datos para calcular estadísticas como la actividad más realizada y los niveles de procrastinación de los usuarios.

## Estructura del Proyecto
El proyecto sigue la estructura estándar de Eclipse:
* `src/Taller_1/`: Paquete principal del código fuente.
  * `Main.java`: Clase principal que contiene los menús, la lógica de validación, algoritmos de análisis y persistencia de datos.
* `Usuarios.txt`: Almacena las credenciales de los usuarios.
* `Registros.txt`: Almacena el historial de actividades.
